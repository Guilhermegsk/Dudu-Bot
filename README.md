# Dudu Bot

**Dudu Bot** é um bot para Discord que permite consultar o cardápio do restaurante universitário diretamente no seu servidor. Ele fornece informações sobre o almoço e o jantar do dia.

## Funcionalidades

- **/menu almoco**: Exibe o cardápio do almoço do dia.
- **/menu jantar**: Exibe o cardápio do jantar do dia.
